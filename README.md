## 注册、开卡、付款

1. 打开页面顶部的注册入口，按页面提示完成注册。
2. 进入卡片页面，查看可申请卡型、身份验证要求以及实际开卡费用。
3. 根据官方充值页面选择币种和网络，核对收款地址与最低充值金额，首次可在允许的范围内先做小额验证。
4. 在商户官方结算页自行填卡。订阅类服务还要确认下个月能否自动扣款，并留出覆盖税费或汇率变动的余额。

## 常见问题

**能付 ChatGPT Plus 吗？**  
Roogoo 官方开卡指南把 AI 订阅列为使用场景。具体能否支付 ChatGPT Plus，以及后续能否续费，取决于卡片、地区与商户审核。OpenAI 要求订阅付款卡由受支持地区的银行发行。此处没有针对特定卡片的实付验证。

**免费开卡、0 费率和最终扣款有什么关系？**  
分别核对开卡、充值、消费、跨境结算和币种转换费用，再把商户税费计入预算。首卡试用和终身权益的费用覆盖范围以官方说明为准。
